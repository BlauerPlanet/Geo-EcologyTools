# Tools I developed during my study programme or related to Geoecological needs

## QGIS 
### MergerClipper.py (for my Master Thesis)
- merges Raster Layers active on QGIS MapCanvas and clips the merged Raster by a **selected** feature from a Polygon Layer

### getFieldNames.py (just to have this syntax saved somewhere)
- extracts and saves field names from active layers on QGIS MapCanvas

## Change_Timesettings_read_Logger [.ahk/.exe] for a course at university)
- Autohotkey script that sets the timesettings for windows, so Data from Acclima Loggers can be extracted with correct timestamps

## Multiling IOC 15.1_c.xlsx and Birdspecies_Dictionary.py (for a course at university)
- extracts specific columsn from the official IOC bird list to create a german latin dictionary for bird names

## Veg%2BB.py (for an internship)
- loads specific ExcelFiles with Vegetation survey data in % and converts it to BraunBlanquet Values (based on hardcoded decisions)

## specroutine.py (for the NdWW24 event)
- extracts data from a spectrolyzer that is saved to clipboard (via its Web Interface) and plots it for the event specific needs
